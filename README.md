# 火箭拍摄模拟器（GitHub Pages 静态版）

这是「火箭拍摄模拟器」的纯静态版本，不需要 Python 后端。

## 功能

- 输入相机/镜头、距离、方位角、火箭高度，预览火箭在画面中的大小和构图。
- 百度地图选点：卫星/标准底图、输入联想、搜索、结果列表、分页、点选回填距离/方位角。
- 支持 CZ-8A、CZ-12 两个外形模型。

## 本地预览

```bash
py -m http.server 8000
```

浏览器打开 `http://127.0.0.1:8000/`。

## 说明

- 搜索使用百度地图 JS API 的浏览器端 `LocalSearch`，浏览器端 AK 在 `index.html` 中；请把正式域名加入百度控制台的白名单。
- 静态版没有后端，不能做用户点位提交/审核。
- 百度地图 POI 只用于展示，不缓存、不落库、不导出。
- GitHub Pages 在国内可能访问慢或打不开；正式主站以后再说。

## 文件

- `index.html` / `app.js`：页面与逻辑
- `data/`：机身、镜头、手机、工位、说明文案
- `libs/`：three.js r137 及加载器
- `models/`：CZ-8A、CZ-12 外部 OBJ
- `.nojekyll`：GitHub Pages 用
